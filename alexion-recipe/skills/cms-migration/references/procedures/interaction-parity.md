# Interaction parity

List observable behaviors from the source: navigation, menus, keyboard/focus, validation, forms, filters, pagination, localization and relevant authenticated/personalized states. Test corresponding target behaviors in a browser.

Record actions, expected/actual observations, route/state, and supporting evidence. Avoid real external submissions or destructive actions unless separately approved; use safe test data.

A successful static render is not an interaction pass. Unsupported integrations or unavailable credentials remain unverified. Report regressions by stable entity ID so redo work is bounded.
