# Visual parity

Use source and target at equivalent routes, viewport, language, data state and relevant interaction state. Capture both with a browser, then inspect structure, spacing, typography, assets, responsive behavior and head metadata.

Record screenshot references and specific mismatches by component/route. HTTP success, server logs and a screenshot file's existence are not proof someone inspected it. If a browser runner is unavailable, report visual verification blocked.

Keep actual user attestation separate from automated comparison. Accepted deviations need explicit scope/rationale; do not label them identical.
