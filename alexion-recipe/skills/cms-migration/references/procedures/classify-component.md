# Classify a component

Join rendering ID, code export/type, source path, usage routes, template/datasource references and data-shaping/resolver evidence. Preserve the original ID; never derive identity from a display name.

Classify included, excluded or unresolved with explicit rationale. Missing source or absent parser findings mean unknown, not safe exclusion. Report detected frameworks, helpers, external dependencies and hazards without inventing complexity values.

Keep scope decisions separate from execution status. An unmappable helper or controller may require a resolver task or approved fallback. Present uncertain exclusions for user review. Output inventory facts and a proposed decision; coordinator records approved scope.
