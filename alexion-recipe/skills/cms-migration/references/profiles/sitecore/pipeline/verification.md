# Verification

Follow [target website verification](../../../../../presentation-composition/references/verification.md) and the approved operation catalog. The tester checks an independently audited target presentation, actual target Layout Service responses, target browser navigation/screenshots, rendering/variant coverage and agreed functional checks against approved source baseline evidence. The user confirms appearance page by page; the orchestrator owns final acceptance.

Use generated `packet.presentation` metadata, canonical domain outcome validation and the existing shared task postflight. The final `verification.approve` decision binds exact current packet inputs and remains separate from technical success. No publishing, remediation, code migration or shared workflow writes occur in the verifier. Report tested routes and limitations; retain pending live checks when no suitable instance is available.
